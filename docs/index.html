The Hybrid Engine Architecture

Engineered with a strict optimization-first mindset. Pulls raw telemetric data locally and enriches specific targets with high-res data from FR24.

Zero-Bloat Cleanup

Standard integrations corrupt your DB. We enforce a strict force_remove policy. No lingering 'Unknown' states in your Home Assistant database.

Timeout 'Freezer' Logic

No flashing entities! If upstream APIs experience load, we instantly freeze data on the last known good state until a fresh payload arrives.

Safe State Restoration

Tracking lists live in fast memory. On server reboots, the specialized RestoreSensor instantly rebuilds your watchlist from encrypted arrays.

The FR24 Overhead Bubble

Because FR24 limits API calls, we developed the Overhead Bubble to protect your IP. Define a tight secondary radius (e.g., 3000m) inside your primary zone. When aircraft breach this bubble, the Hybrid Engine wakes up and requests rich data (Origin, Destination, Airline, Photos) without creating map trackers!

Offline Ghost Tracking

Want to track a flight before it even takes off? Type a callsign into the Target Lock entity while it's sitting at the gate. SkyRadar Fusion creates a "Dummy" entity and instructs FR24 to fetch data anyway.

Before takeoff, your dashboard populates with photos, routes, and scheduled times alongside an mdi:airplane-off icon. Once transponders turn on, it seamlessly merges into live ADS-B coordinates!

Global Emergency Radars

Continuously scans the global airspace for the universal emergency transponder code (Squawk 7700). Any aircraft squawking 7700 instantly gets a dedicated map tracker, fully enriched, with live distance to your home. Also supports Global Military Radar.

Advanced ADS-B Filters

Hardcore enthusiast? Bypass simple checkboxes. Enter raw ADS-B Emitter Categories (e.g., A1, A3, A5) into the Advanced Filter box. The integration will strictly fetch FR24 data ONLY for aircraft broadcasting those exact codes!

Local Liveries (Custom Icons)

External APIs missing experimental or private jets? Inject your own icons. Drop transparent PNGs into /www/planes/ matching the uppercase ICAO type signature (e.g., B77W.png). Maps will prioritize these custom assets!

Installation & Setup

Get your airspace monitored in minutes via HACS.

Step-by-Step HACS Install

  1. 1
    Open HACS in your sidebar and navigate to the Integrations panel.
  2. 2
    Click the three dots (...) in the upper right corner and select Custom repositories.
  3. 3
    Input the repository web link (GitHub URL).
  4. 4
    Set the Category selector dropdown to Integration and hit Add.
  5. 5
    Locate the SkyRadar Fusion repository card and hit Download.
  6. 6
    ⚠️ Restart your Home Assistant instance. (Crucial for loading new Python modules).
  7. 7
    Navigate to Settings > Devices & Services > Add Integration and search for SkyRadar Fusion.

Tracking Modes

1. Zone Tracking (Recommended): Monitor airspace around your home. Set your Latitude, Longitude, and a metric Radius. Aircraft are counted but don't clutter your map.
2. Target Tracking: Deploy a dedicated instance to track ONE unique airframe globally using Callsign, Registration, or ICAO Hex.

Crucial Database Step

SkyRadar uses a "Zero-Bloat Memory Buffer". To prevent SQL limits, you must exclude the main sensor in your configuration.yaml.

yaml 
recorder:
  exclude:
    entities:
      - sensor.skyradar_fusion_current_in_area

* Historical data survives reboots backed up to .storage folder.
